# ランダム引換券つくるしょうへいくん改

在庫CSVを読み込み、入力した基準値の83%台・84%台・85%台から選んだ割合になる在庫の組み合わせを探すブラウザアプリです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 在庫CSVを選択します。
3. 商品名・組み合わせる数字・在庫数に使う列を選択します。
4. 「相場合計の割合」で83%台・84%台・85%台を選びます（初期値は83%台）。
5. 基準にする数字を入力し、「選択した%台の組み合わせを探す」を押します。

83%台は83%以上84%未満、84%台は84%以上85%未満、85%台は85%以上86%未満です。割合を変更すると前の結果は消えるので、もう一度検索してください。

CSVはUTF-8とShift_JISに対応しています。CSV自体は外部へ送信されません。候補の画像を表示する際は、N列の画像URLへアクセスします。

指定の在庫CSVでは、次の列が自動選択されます。

- B列「管理名称」：結果に表示する商品名
- G列「保管場所別在庫」：使用できる数量（`fred:84` のような `fred` の数量だけを使用。他の保管場所や数字だけの値は無視）
- J列「現在相場（スニダン直近取引）」：合計に使用する数字
- N列：同じ行の商品の画像URL（HTTP/HTTPS）。候補の商品名の横に小さく表示します。空欄・無効なURL・画像の読み込み失敗時は画像を表示せず、候補と金額はそのまま表示します。

J列が空欄または0の商品と、G列の `fred` の在庫が0、または `fred` がない商品は組み合わせから除外されます。

候補は1商品で完結するものを優先し、通常は最大2枚まで組み合わせます。「3枚の組み合わせも表示」「4枚の組み合わせも表示」にチェックすると、指定した枚数の候補も枚数別に追加表示します。表示件数は通常の1〜2枚の候補、および追加した枚数ごとに適用します。同じ商品は1人につき1枚までです。3・4枚は金額の偏りが小さい候補を優先し、それぞれ探索上限に達した場合は画面に通知します。2個の候補は相場金額の比率が5:5に近いものから順に表示します。ランダム設定は同じ優先度・比率の候補同士に適用し、オフの場合は同じ比率なら相場合計が高い順に表示します。同じ商品を2個使う候補は除外します。「なにかのPSA10」と、管理名称に「BOX」を含む商品は候補から除外します。

候補には各商品の相場単価を表示します。同じ商品を2個使う場合は単価×個数の小計、異なる2商品の場合は各小計の足し算と相場合計を表示します。「結果をコピー」にも同じ内訳を含めます。

候補の画像をクリック・タップすると、N列の元画像を大きく表示します。閉じるボタン・背景クリック・Escキーで閉じられます。画像の鮮明さは元画像の解像度に依存します。

## 複数人への一括割り当て

在庫を読み込んだ後、「複数人分をまとめて割り当て」で名前・基準coinのCSVを選択します。名前の列と基準coinの列を確認し、「全員分の組み合わせを作る」を押してください。「商品名」に含まれる `108,804coin` などの表記、または数値だけの列を使用できます。

一括割り当ては1〜2枚。相場の割合は上の設定を使い、全員分で在庫を共有します。同じ人に同じ商品は入りません。1枚の候補を優先し、2枚では相場比率が5:5に近い候補から探索します。在庫の競合がある場合は割り当てを調整して、割り当て可能な人数を増やします。探索上限に達した場合は、その旨を表示します。未割当の人は理由を表示します。

各人の候補は最大20件です。画像付きのドロップダウンで各候補のカード画像・商品名・単価・合計相場・割合・枚数を比較できます。候補のラジオボタンで選択し、画像をクリックすると拡大できます。画像URLがない商品や読み込みに失敗した商品も、名前と相場は表示します。初期状態は全員未確定で、「この組み合わせで確定」のチェックを付けた人だけ在庫を使用します。他の人の確定分で在庫が足りなくなる候補は選べません。確定した人の候補を変更すると、在庫が足りる場合だけ入れ替わり、チェックを外すと在庫が戻ります。「おすすめ」は全員の同時割り当てを探索して選んだ候補です。

「チェックした組み合わせをCSV保存」は確定した人だけを出力します。使用数・残在庫も確定分だけを集計し、出力前に在庫を再確認します。名前の絞り込みは表示だけに適用され、表示していない確定分もCSVに含まれます。元の在庫CSVは書き換えません。CSVや割合を変更したら結果とチェックを破棄し、再計算してください。単独検索も同じ商品の重複を禁止します。

ローカル起動：`node local-server.mjs`。`http://127.0.0.1:8766/?local-example=1` を開き、「今回のCSVで表示」を押すと今回の在庫・名前CSVで計算します。ローカルサーバーは127.0.0.1だけで待ち受け、指定の2ファイルだけを読み込みます。これらのCSVとローカルサーバーは公開用ファイルに含まれません。

検証：このフォルダで `node batch-engine.test.cjs` と `node batch-ui.test.cjs`。

## CSV例

```csv
商品名,数字,保管場所別在庫
引換券A,500,fred:3 / 東京:20
引換券B,300,fred:5
```

計算量が極端に大きくならないよう探索回数には上限があります。在庫の種類や数量が非常に多い場合、存在する組み合わせをすべて表示できないことがあります。

## Renderで公開

このフォルダをGitHubリポジトリのルートとして登録し、Render Dashboardで **New > Blueprint** を選んでそのリポジトリを接続します。`render.yaml` が読み込まれ、静的サイト `random-voucher-shohei` が作成されます。在庫CSVやサンプルCSVは公開ファイルに含まれません。
